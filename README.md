# P12-testeur-logiciel-portfolio
# Portfolio Professionnel - Développeur Web & Testeur QA

Ce dépôt contient le code source de mon portfolio professionnel, développé et optimisé dans le cadre de ma formation OpenClassrooms. Il présente mes réalisations en développement web front-end ainsi que mes compétences en Assurance Qualité (QA).

🌐 **Site accessible en ligne :** [https://yannd38-coder.github.io/P12-testeur-logiciel-portfolio-master/](https://yannd38-coder.github.io/P12-testeur-logiciel-portfolio-master/)

---

## 🛠️ Stack Technique & Outils

- **Front-end :** HTML5, CSS3, JavaScript (ES6+), Bootstrap
- **QA & Tests :** Cypress (Tests E2E), rédaction de cahiers de recettes / spécifications
- **Optimisation & SEO :** Google Lighthouse, Squoosh (compression WebP)
- **Hébergement & Versioning :** Git, GitHub, GitHub Pages

---

## 🚀 Projets Présentés

1. **Booki :** Intégration responsive HTML/CSS à partir d'une maquette Figma (Mobile-first & Accessibilité).
2. **Kasa :** Développement front-end d'une application de location immobilière en React.
3. **Eco-Bliss-Bath :** Élaboration d'une stratégie de test, cahier de recettes et automatisation de la suite de tests E2E avec Cypress.

---

## ⚡ Optimisations & Qualité

- **Performances :** Images optimisées et converties au format `.webp`, gestion du rendu CSS/JS.
- **Accessibilité & Layout :** Cartes dynamiques alignées via Flexbox, respect des contrastes et de la sémantique HTML5.
- **Principe KISS :** Code simple, lisible et facilement maintenable.
- **Scores Lighthouse :** ~95+ en Performance, 100 en Accessibilité, Bonnes Pratiques et SEO.
